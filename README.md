# Cyber Risk Register Template 🛡️

A professional-grade, automated Excel-based template designed for Cybersecurity professionals and GRC (Governance, Risk, and Compliance) analysts. This tool streamlines the process of identifying, analyzing, and treating cyber risks.

## 📋 Overview
This register is aligned with industry-standard frameworks such as **NIST SP 800-30** and **ISO/IEC 27005**. It allows organizations to move away from static lists toward a dynamic risk management approach.

### Key Features
* **Automated Scoring:** Dynamic calculation of Inherent and Residual risk scores.
* **Heat Map Integration:** A visual 5x5 matrix that updates based on your data.
* **Treatment Tracking:** Monitor the progress of mitigations (Accept, Mitigate, Transfer, Avoid).
* **Framework Mapping:** Cross-reference risks with NIST CSF or ISO 27001 controls.

## 📊 Methodology
The template utilizes a standard qualitative-to-quantitative risk assessment model.

### Risk Calculation
The risk score is calculated using the following logic:

$$Risk\ Score = Likelihood \times Impact$$

| Score | Rating | Action Required |
| :--- | :--- | :--- |
| 15-25 | **Critical** | Immediate remediation or executive escalation. |
| 10-12 | **High** | Prioritized mitigation within 30 days. |
| 5-9 | **Medium** | Planned mitigation within the quarterly cycle. |
| 1-4 | **Low** | Routine monitoring or risk acceptance. |

## 🚀 How to Use
1.  **Download:** Click on the `Cyber-Risk-Register-Template.xlsx` file above and select the **Download** button.
2.  **Define Assets:** Start by listing your critical assets (e.g., Customer Database, VPN Gateway).
3.  **Identify Threats:** Use the dropdown menus to select threat sources and vulnerabilities.
4.  **Score Risks:** Input the Likelihood and Impact based on your current control environment.
5.  **Assign Owners:** Ensure every risk has a designated stakeholder for accountability.
